# Fitness V8 合成评测报告

日期：2026-10-11。模型：DeepSeek Flash。范围：规范第 2 部分第 8 节的五项新增情境及四类 V8 任务，中英两种语言，共 28 项。所有输入均为人工构造的合成数据，没有读取用户训练资料、备份或备注。

## 结论

本轮不能作为生产启用的质量验收。28 项中，24 项尝试调用模型，4 项未成年输入在本地拒绝。22 次调用留有响应和用量；其中 17 份是合法 JSON、5 份非法 JSON。另 2 次早期尝试未留下可判定的响应，未重试，费用上限仍计入预留。

17 份合法 JSON 在原适配器中通过 16 份。离线复审发现一份英文回复将 `missingCount: 4` 编成了 `notStarted: 4`，实际 `notStarted` 为 0。增加针对明确中英次数陈述的校验后，15 份通过、2 份拒绝：事实次数矛盾和缺少 `proposal.reasons` 各一份。该校验不能证明任意自然语言都没有事实错误。

测试运行器最后显示的“28 passed”仅表示各测试项已执行、记录或跳过已尝试项，不是 28 项质量通过。历史模型输出未修改；更新提示词和适配器后没有再次调用模型。

## 已验证与未验证

- 对 17 份可解析输出执行现有 `checkCoachLanguage`，没有命中禁用词类别。现有词表主要覆盖规范明确列出的词语和符号，不是完整的中英语气审查。
- 7 份可解析回顾都含 opening、encouragement、gap 和非空 dataBoundary；这里只验证字段存在，不证明叙述顺序、事实或建议质量全部合格。
- 4 份疼痛情境回复包含停止疼痛动作或评估提示，但部分同时提出替代动作。未进行临床适用性评价，不能据此作安全认证。
- 拒绝发送备注的输入没有携带 history 或真实备注；出现的次数幻觉说明“不发送备注”与“回复事实可靠”仍是不同验收项。
- 非法 JSON 和缺少必需字段均拒绝接受；没有自动修复模型响应或自动重试。
- 4 个未成年场景仅验证本地拦截，没有向模型发送未成年资料。

## 费用与耗时

授权上限为 28 次调用且不超过人民币 10 元。实际计数为 24 次尝试，按输入 UTF-8 字节数加协议余量预留 token 上界，每次输出限 2,000 token，全部预留合计人民币 1.92 元。

22 次有用量的响应累计输入 194,661 token、输出 11,284 token。按官方高峰费率及返回的缓存命中数估算人民币 0.217425 元；另外 2 次未知响应保留人民币 0.16 元预留，两者相加不超过人民币 0.377425 元。这是保守估算，不是账单结算证明。未修改生产账本或预算策略。

已知响应耗时最短 1.497 秒、最长 3.948 秒，中位数 2.662 秒。实际输入约 8,600–9,027 token，超过最初 8,000 token 的建议值；硬费用限制使用实际发送字节上界，不依赖该建议值。

价格依据：[DeepSeek 官方价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。本次使用每百万 token 的高峰价格：未缓存输入人民币 2 元、缓存输入 0.04 元、输出 8 元。直接打开页面超时，核对依据为官方页面在联网检索中返回的完整价格表。`price-source.json` 保存归一化价格事实；其哈希不是远端网页原文哈希。

## 产物与后续边界

- `synthetic-evaluation.json`：原始合成输入、响应、用量、耗时及失败记录；保留最初两次诊断不足的事实，不补造原因。
- `offline-language-summary.json`：当前适配器离线复放结果、禁词及四段字段检查。
- `price-source.json`、`artifact-hashes.json`：价格依据及本地产物哈希。

哈希按 UTF-8 文本、换行统一为 LF 计算，避免 Windows 的 Git 换行转换改变校验结果。

后续应先人工复审事实、器械、动作适用性和建议质量，再考虑另一轮单独授权的真实评测。不得把本次离线修复称为模型质量已经恢复。所有付费调用已停止；评测密钥没有用于生产，也未写入这些产物。
