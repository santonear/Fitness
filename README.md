# Fitness

面向普通健身用户的手机优先 Web 应用，兼容电脑。支持力量、有氧和居家徒手训练，围绕 AI 辅助制定计划、执行训练和跟踪进度展开。

首版无需登录，本地保存数据；后续增加账号和云端保存。项目当前处于设计阶段，尚无应用代码。已形成 React/TypeScript/Vite、Cloudflare Workers、IndexedDB 的技术建议，待设计审阅与验证。
