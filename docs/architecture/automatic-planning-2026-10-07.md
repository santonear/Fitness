# 对话到训练计划

本次决定取代生产页面中逐次预览、确认理解、手选训练日期、再确认生成的流程。用户已确认：同一窗口沟通，信息齐全后自动生成计划，最后确认采用；默认用户时区下从明天开始的未来七个日历日。

## 行为

- 有效试用页提供制定计划入口。尚未完成引导的用户先完成现有引导；再次进入时读取本地进度。资格在进入、重新获得焦点及恢复联网时查询，失败不伪造有效状态。
- 用户发送消息时显示统一额度说明：理解使用一次理解额度；信息充分后自动生成使用一次生成额度；调整计划使用一次生成额度；采用已有计划不调用模型。
- 理解请求携带本次消息、近期已发送的目标对话及训练条件，不自动附带身体数值或训练历史。仅本地保存的想法不自动外发。AI 汇总当前目标、频次、时长、场地器械、经验和限制；必要信息不足时继续追问。
- 理解返回无待补充项时，使用返回的完整摘要构造生成请求，重新核实准入状态后调用现有生成接口。明确要求生成可执行训练内容，不只返回建议或摘要。
- 自动日期模式的日期列表表示允许窗口。AI 可以选择非空子集，不能越界、重复或使用无效动作与训练指标。原精确日期模式及候选修订仍保留精确日期校验。
- 界面按日期及动作顺序展示目标组数、次数/时长/负重/距离、AI 备注与休息安排，并提供标明来源的动作目录指导。用户采用后才写入本地计划和日历。

## 失败与边界

自动生成与理解使用各自的请求标识。生成失败后明确重试仅复用生成请求，不重新理解，也不暗中创建新付费请求。后端原有去重、月预算、费用预留及次数规则保持有效。

资格或核算状态未知时暂停自动生成，保留已整理的目标。取消、输入变化、恢复代次变化或本地条件变化时停止使用旧结果。已返回的计划可以本地存档、刷新后查看和采用；存档失败只能重试保存已有内容。

日期采用本地日历运算，避免跨年和夏令时引起的错日。生成后的具体日期以候选内容展示，采用时继续由本地服务检查冲突及资料版本。

本地合成演示保留旧的逐步契约测试入口；生产交互不显示这些入口。浏览器夹具验证流程和数据边界，不代替真实模型的训练内容质量验证。
