基线：0c70643171ff3ffb8648b80acf458417bfcaa22c。

## 四项独立范围

| 范围 | 主要文件 | 验收重点 |
|---|---|---|
| AI 页面与客户端 | src/ai、AiPage、AiCandidateEditor、App、PlansPage | 默认关闭；本地演示明确标示；每次发送确认；目标变化失效；取消与旧响应隔离；候选仅明确确认后保存 |
| 控制后端与传输 | src/backend/control、http、worker、supplier-transport、wrangler.backend.jsonc | 缺配置拒绝启用；单次传输无自动重试；预算预留；不确定费用待核算；凭据留存与账本保留区分 |
| 一致上下文与候选保存 | src/application/ai-context、ai-candidate-save | 单事务只读捕获；显式历史范围；不截断；精确日期；恢复代次失效；相关依赖复核；原子保存与重复拒绝 |
| 动作媒体 | src/catalog/media、ExerciseMedia、CatalogPage、public/media | 原创本地图；显式加载第三方视频；来源与验证状态；失败回退；目录及训练事实不变 |

## 共同契约

沿用 AiRequest v1、CAL 日期模型和 JSON2/3。当前请求日期上限 K=1、本地保存 B=1；更大边界另行测量。候选日期严格对应请求，不静默增删日期。保存前校验动作目录、四种指标、目标与来源。

capture(scope?) 在一个数据库只读事务捕获 profile、dataRevision、restoreGeneration 和可选历史。历史默认不包含；只有指定范围才能产生 text/manifest；超过 UTF8 字节边界整体拒绝。捕获不重建备忘、不写库、不联网。

prepare(request,candidate) 不写库，产生服务拥有的不透明令牌。save(token,edits) 在最终数据库写事务检查恢复代次、时区、相关条件、选定历史、日槽与进行中保护，再原子新增 plan/version/task。无关写入不一概失效；整库恢复必失效。失败保留候选及可重试令牌，成功请求不能重复落库。不生成训练完成事实。

客户端默认关闭。页面内显式演示使用内存控制服务与合成响应，不使用真实模型、资格 cookie 或外部请求。网络客户端仅提供同源接口适配，不默认启用。未知资格状态不能显示为零。

控制 Worker 使用独立配置，默认 disabled、无云资源绑定或路由。原静态 Worker 配置保持不变。供应商编解码器尚未选定；通用 Fetch 接口不代表任何模型 API 已实现。密钥仅服务端。失败或取消不承诺费用回滚，未知费用继续占用预留。

媒体外连不包含训练记录。视频仅点击后加载，无远程缩略图、默认 iframe 或自动播放。素材来源匹配、内容审阅和实际嵌入可用性分别记录；缺失或未审阅不能声称通过。

## 复用与集成

复用现有 React、Zod、Dexie、预算事务、历史整理、日期占用及本地备份；无新增依赖。共同领域、持久化、备份和依赖配置不作无关修改。上下文/保存契约先接入页面；控制传输与媒体分别集成；冻结源码后运行完整检查。

验证命令：npm.cmd run check；node node_modules/@playwright/test/cli.js test --config playwright.next-integration.config.ts；Wrangler 后端 dry-run。隔离合成库及专属测试端口，不访问用户训练库。实际 D1、模型、费用、真机及生产发布均不由本地模拟结果证明。
