## 共同边界

现有日期模型、K=1/B=1、备份上限及恢复原子性、手动入口、主动逐组保存、完成历史只读保持。复用React/Zod/Dexie/现有统计和Fetch，无新增依赖。本阶段运行形态为本地及模拟环境；真实 Worker/D1、生产模型、供应商费用及真机属于独立验证范围。

公共domain/persistence/backup、contracts/store/control/http、依赖与App路由统一整合，不由独立范围同时编辑。B不改变实际训练统计；C不改变请求/候选公共协议；D不把未审阅示意图或视频标为专业合格；A的同源状态/兑换不代表云端已部署，真实生成仍须后续资源与供应商配置。

## 验证与集成

每项采用必要的行为回归；普通改动一次针对性审查，涉及鉴权及保存的整合增加独立检查。先冻结各范围源码，再只合入指定文件。npm.cmd run check；隔离Chromium/WebKit全量回归；模拟请求截获不得外发；下载和事实保真边界使用既有有效证据并在相关变化时复验。键盘测试等待SPA导航渲染，保留五目标断言。

独立验证配置使用5211、5212，整合配置使用5213，输出分别写入test-results子目录。
