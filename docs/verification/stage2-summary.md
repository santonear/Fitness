# 阶段总结本地准备

依据 SDD R17–R19，进度页提供手动本地预览，不调用模型、不外发数据、不保存总结，也不修改备忘、计划、日程、训练或体重。

## 范围与事实

- 自选日期包含首尾，以 session.localDate 选择已完成训练，同时包含临时训练。
- 某周由用户选择起始日，连续包含七个日历日；按 planId 限定训练，跨同一计划版本，不推断 ISO 周或固定星期。
- 整份计划包含同一 planId 的各版本。旧周计划覆盖 startDate 起 durationWeeks × 7 个日历日；日期计划保留原始单日。取这些原始周期的首尾作为可见范围；范围外的实际补练不包含在训练明细中。
- 完成率复用 calculateProgress：任务按 originalDate 及来源版本时区到期，补练回计原任务，跳过、隐藏和漏练保留原统计口径。实际训练日期选择与原任务统计分别展示；关联依靠 task/session/version/day 身份，不按同日合并。
- 体重是资料级观测，按所选日期范围包含，不称为计划所属数据。四种指标保留原类型，缺失保持空缺，已记录的零保留为零；仅已完成组参与预览。
- 目标按计划及版本标明来源，不推断共同目标。无完成训练且无体重观测显示 EMPTY_STAGE；无效范围或未选计划显示 INVALID_RANGE；引用不完整显示 INVALID_FACTS。

## 一致读取

prepare 在一个 Dexie 只读事务中读取 metadata、plans、planVersions、sessions、sets、scheduledWorkouts、bodyWeights，直接捕获 dataRevision 和 restoreGeneration。随后复用纯 buildHistoryContext 构建身份清单与事实。该路径不读取或重建训练备忘，不使用 repository.write。

预览展示日期、展示时区、各训练及观测原时区、截止时刻、数据修订、恢复代次、记录数量、原任务完成率、目标来源及只读明细。时区优先读取保存资料的 IANA 时区；资料尚不可用时明确标为浏览器显示时区，不重新映射已有 localDate。选择变化会清除旧预览。模型仍未启用，发送流程与下一阶段计划建议属于后续功能。
