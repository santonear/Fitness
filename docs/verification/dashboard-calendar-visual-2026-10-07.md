# 记录面板与训练月历

依据界面参考重组记录面板，沿用暖白、炭灰、松绿及既有字体字重规范。完成环使用实际计划任务数量，零任务显示未知；时间进度与训练完成分开展示。身体概览使用已有观测，缺测不填零，记录表单折叠为主动入口。

新增只读训练月历，读取当前计划任务及版本。桌面月历与当日安排并列，手机上下排列；点击日期展示动作、逐组目标、备注和完成/跳过状态。隐藏任务不进入可见日程，改期仍展示原统计日期。无训练时间字段时不编造时间。未改变槽位、计划生命周期、统计、数据库或备份契约，未增加通知和同步。

验证：Windows 本地 5230 合成环境；TypeScript、构建及差异格式检查通过。构建仍有既有大包警告。浏览器用例新增日历任务显示、翻月不改变本地数据、1440px 桌面与320px手机无横向溢出检查。已人工查看中英文流程所生成的中文桌面与手机截图；真机尚未验证。
