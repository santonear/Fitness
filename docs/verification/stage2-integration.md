## 发布与支持边界

本地实现不等于公网或真实AI已上线。Worker/D1、生产origin绑定、供应商、真实费用、留存、安全和手机端到端仍需独立验证。阶段总结4次额度不转为理解/生成额度。真实手机继续未验证；Windows WebKit不代表iPhone Safari。

静态站点没有控制API时，连接显示未知，不伪造资格。源码中的真实模型仍默认关闭，无新增云资源或模型调用；媒体模拟失败不证明视频可播放。公网发布版本仍为基线对应的现有版本。
