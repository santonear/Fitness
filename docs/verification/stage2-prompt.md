# 模型无关提示与离线诊断

`src/backend/prompt.ts` 提供 `buildAiPrompt(value, maxInputBytes=65536)`。构造前复用 AiRequest v1 的形状、外发确认、目标确认、恢复代次及精确日期验证，固定 K=1。返回提示版本和 system/user 两条消息，不选择供应商、不读数据库、不联网、不调用模型。

目标理解仅包含目标原文与语言。生成包含原文、已确认目标、日期、时区、目录版本、确认请求中的全部条件，以及明确选择的历史范围；未选择历史时不添加历史字段。请求 ID、恢复代次、确认散列不发送给模型。系统消息提供受控动作目录、四种指标、公制单位、成年人一般健身范围及预览要求。用户自由文本、条件和历史统一放入 JSON 数据消息，文本不拼入系统指令。这种隔离不能保证模型绝对抵抗提示注入；没有医学关键词过滤或医疗诊断。

`evaluateAiCandidate(validatedRequest, result)` 先复用严格候选验证，包括精确日期、目录 ID、指标字段和顺序。`schemaValid` 表示现有候选协议和硬约束通过，不代表内容合格。函数额外返回器械及显式时长诊断，不接入保存阻断规则：器械仅在输入全部属于当前受控值 `none` / `dumbbell` 时比较，未知器械不推断；时长仅累计计时型目标组，是不含次数动作、休息和转换的下界。没有诊断不表示完整满足时间或训练条件。

所有结果均返回 `contentQuality: 'not-assessed'`。语言自然度、目标忠实性、训练适宜性、范围拒绝、器械未知值、经验与偏好适配、内容安全及真实费用仍需供应商候选和人工评估。当前理解候选仅含 interpretedGoal，未提供结构化范围拒绝字段；提示范围说明不证明 R8 的机器可验证拒绝闭环。

固定合成案例在 `tests/fixtures/prompt-cases.ts` 与 `tests/backend/prompt.test.ts`，覆盖中文/英文、四指标候选、理解最小化、生成完整条件、选择历史、恶意目标/条件/历史数据隔离、失效确认、K=1、容量、未知动作、增删日期、缺字段、错误指标、多余字段、损坏输出，以及 schema 合法但器械/时长诊断失败。测试不使用真实个人资料。

验证：12项针对性单元通过；整合168/168单元、类型检查与构建通过。没有先行有效RED证据，不宣称红绿验证。此结果仅证明纯函数及固定合成案例，不证明真实模型内容质量、延迟或费用。
