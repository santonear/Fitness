# 引导版回归用例迁移

手动建计划入口已由引导式对话替代；旧数据及其查看、训练、隐藏、删除和备份语义继续保留。回归适配不恢复已取消的产品入口。

| 原用例 | 当前验收 |
|---|---|
| 手动建立周计划后删除、补练、离线记录、阶段总结 | 从原服务建立隔离旧数据，继续真实 UI 操作和逐字段事实断言 |
| 手动改名与复杂课表 | 保留服务及合法 JSON 改名保真、并发和进行中保护；界面仅只读查看，无旧编辑入口 |
| 手动单日创建、逐日草稿 | 新日历月/日视图、选择不产生事实；候选原子保存、冲突、恢复代次及失败由 guided-lifecycle / guided-backup 覆盖 |
| 旧 AI 连接按钮、旧候选编辑表单 | 新试用查询/兑换、逐次发送确认、理解编辑、完整候选确认、本地保存与未知资格保留 |
| 旧首页概览 | 新 analytics 的真实完成事实、空态、过滤、响应式及持续训练入口 |
| 旧 JSON / 数据库版本号 | 新导出 JSON4、数据库5；旧库升级逐字段比较不包含新增空表，旧事实仍完整比较 |
| 大备注容量夹具 | 使用当前导出格式和 guidedStates；保留实际下载、导入及完整事实比对 |

默认 Playwright 套件启用本地演示。三个 HTTP 资格/对话套件在独立生产传输配置中运行；CI 同时执行两种配置，没有把模型 mock 验证当作供应商实测。所有控制接口拦截只存在测试文件。

真实设备仍未验证。执行结果以最终提交的测试记录和 CI 为准。
