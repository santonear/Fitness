# AI 候选页面与发送确认

默认 AI 关闭；计划页提供独立 AI 入口，主导航保持五项。本地演示需显式进入，使用内存资格与合成响应；不联网、不创建云资格、不调用真实模型。演示输出不是训练建议。Fetch 客户端提供同源 /api/v1 适配，但页面不默认启用。

目标理解只包含目标文本、语言和必要请求上下文。日计划请求包含已确认理解、单个具体日期、保存的日历时区、明确训练条件及可选历史。请求完整 JSON 与历史清单可预览；拒绝发送仍可使用本地功能。目标变化清除理解与发送确认；其他条件变化清除对应发送确认。

发送前重新捕获一致快照，校验恢复代次、相关资料和选定历史。普通无关写入允许重新核对而不直接丢弃候选；相关变化需要重新预览。候选日期严格对应请求且受控动作/指标校验通过后才可编辑。明确保存前不新增计划或训练事实。

取消忽略旧响应，延迟取消失败不能覆盖较新请求状态。取消、超时和供应商失败不承诺费用回滚。未知状态不显示为零；网络错误只显示允许的公开错误码，未知正文不直接展示。请求无自动重试。

保存失败保留当前页候选和编辑。保存服务使用不透明令牌及最终事务保护，恢复代次变化使令牌失效；成功请求不能重复保存。刷新恢复、跨设备草稿、真实模型和阶段总结不属于当前行为。

验证：ai-workflow/ai-client/ai-preview-guard 单元测试；ai-public-flow 浏览器测试覆盖中英文完整本地演示、确认变化、候选修改和本地保存。next-context 浏览器测试另覆盖恢复失效、事务失败、冲突和事实保真。完整结果见 next-integration.md。
