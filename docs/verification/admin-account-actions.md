# 管理员单用户操作

基于已发布PR17（2f60f091），分支 `codex/admin-account-actions`。

用户确认的规则：删除资格、会话与关联激活码，并从正常列表移除；保留费用、用量、审计和设备训练数据。已申请用户免码开通30天，原申请浏览器刷新后可使用；重复操作不延长或重置。新增“刷新额度”沿用本月剩余次数恢复到默认上限的既有机制。

## 实现

- 申请审核的新申请卡片增加“免激活码激活”，资格期限从管理员确认时起计算。已批准但未领取的申请也可直接开通。自动领取仍需原申请凭证，响应丢失可恢复，不允许其他凭证领取。
- 试用资格的每个用户卡片增加“删除账号”“生成此用户激活码”，保留“撤销资格”，额度入口命名为“刷新额度”。操作均需确认；额度刷新需原因。
- 单用户激活码是补发：旧码及旧会话立即失效，新码一次性、7天内且不超过原资格期限兑换，不延长资格或重置用量。通用“手动生成邀请码”入口保留。
- 删除采用资格删除标记，不能用旧码、旧会话、原领取凭证或免码激活恢复。账务与历史记录保留；没有访问或删除设备训练数据库。
- 管理接口继续经过Cloudflare Access、服务器管理员凭证、同源检查与严格输入验证。变更在既有事务中原子保存，无D1表迁移。
