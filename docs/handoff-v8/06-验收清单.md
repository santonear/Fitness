- [ ] 按压回弹：所有可点击控件生效；参数 0.96 / 420ms / `cubic-bezier(.18,1.36,.3,1)`
- [ ] 主卡流光描边 + 呼吸背光：只出现在规定的 3 类主卡；训练页关闭
- [ ] 胶囊 → 面板变形：520ms 打开 / 420ms 收回；焦点进出正确；Esc 可关
- [ ] 减少动态效果模式下无持续动画、无缩放
- [ ] 字体已打包并子集化，离线可用；字体包大小已报告
- [ ] 外观偏好迁移：atlas / serene / orbit → qingci
- [ ] 导航陶瓷图标 `NavIcon`（青瓷釉）：64×64 视框、44–50px 呈现、选中加粗釉边、按下下移 2px、渐变 ID 唯一
- [ ] 主题切换不重新挂载路由或业务状态
- [ ] 截图：青瓷 下一次 / 训练中 / 计划 / 回顾 × 390 / 1440

## 第 2 阶段：训练闭环

初见与计划

- [ ] 三个问题，每题有"你也许想说"建议回答，可打字
- [ ] 安全确认：未勾选年满 18 岁时不能生成计划；未满 18 岁只开放手动训练与记录活动
- [ ] 轻量外发同意：生成按钮旁可展开"将发送给芽芽"字段清单；身体资料与历史默认不发送
- [ ] 三问答案按规范第 3 部分 C.2 写入 12 字段引导契约；未问到的字段为 skipped；备份结构不变
- [ ] 没有 AI 资格时生成本地基础计划，可立即开始训练
- [ ] 计划草案：训练单 + 每周目标 + 3 条理由，无任何日期；保存前不写入
- [ ] 旧引导资料迁移为已确认条件，用户不必重填

首页与训练

- [ ] 下一次：按训练单轮换；可换另一份；显示本周已练/目标；有进行中训练时显示回到训练
- [ ] 训练中：默认值带入；点数字修改；完成一组后显示正计时"已歇"；无倒计时、无自动跳转、无弹窗
- [ ] 动作可自由切换；已完成带勾
- [ ] 暂停：继续 / 结束并记下 / 放弃（不记录）
- [ ] 同时只有一个进行中训练；离开后可返回
- [ ] Wake Lock 生效（支持的浏览器）
- [ ] 可选休息轻震默认关闭

记录与反馈

- [ ] 结束页：完成组数、用时、本周第几次；三种开场文案按情况出现
- [ ] 感觉与少练原因可不选；原因仅在部分完成时出现
- [ ] 记录活动：类型、时长、时间、感觉；计入"其他活动"，不计入计划次数
- [ ] 完成记录只读，可追加备注

计划与回顾

- [ ] 计划页：版本号、目标、节奏、训练单胶囊、提醒（默认关闭，文案"只是提醒，不代表必须练"）
- [ ] 提醒复用 V6.2 引擎：仅用户设置的提醒，移除完成后与闲置关怀提醒；前台、每日上限、静默时段、多标签认领规则通过测试；提醒日未练不产生任何记录
- [ ] 版本页：每个版本的日期、来源、改动明细
- [ ] 周回顾：事实、差距、规律、最多 1 条建议；采纳后生成新版本；"先不改"后本周不再出现
- [ ] 月回顾：每周柱状图（完整/部分区分）、合计、规律、建议
- [ ] 数据边界文案：涉及体重或减脂时说明"饮食这部分芽芽看不到"；无体重记录时只邀请记录、不下结论
- [ ] 回顾计算单元测试覆盖产品规范 6.1、6.2 每条规则
- [ ] 话术禁用词检查在 CI 中运行

AI 契约

- [ ] ONBOARD_PLAN / ADJUST_TODAY / MODIFY_PLAN / PERIOD_REVIEW 请求与响应 schema
- [ ] 所有会改数据的返回 `mutationAllowed:false`，确认后由应用执行
- [ ] 废弃 date_plan_candidate、management_proposal，并删除相关代码路径
- [ ] 无模型时本地规则兜底，界面一致
- [ ] V8 新任务的提示词在后端以新版本登记，生产包不含提示词正文
- [ ] 芽芽浮动按钮在初见、草案、结束反馈、记录活动隐藏；训练中为顶部小头像；不遮挡任何主操作（320px 验证）

迁移

- [ ] 新 DB 版本迁移：日期计划 → 训练单版本（origin: migrated）；历史记录保留
- [ ] 幂等；失败不部分写入；导出备份可恢复
- [ ] 至少 3 份旧版本真实UI导出备份样本验证报告
- [ ] 迁移后一次性提示"以前排的日期可以改成提醒"
