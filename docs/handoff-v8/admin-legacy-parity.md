## 本次缺口处理

- 开关入口：/admin 请求携带同源凭据；模拟受保护域名拒绝无凭据请求，实际管理页仍进入新后台。503 明确提示，重试可恢复，不静默显示旧页面。
- 枚举：申请、请求、流水、操作记录、质量和错误分类均有中英映射；未知项中性显示。版本及模型标识保留原标识。
- 费用：按任务筛选同步影响日图、任务图和表格。
- 配置：金额以元编辑及确认，以分保存。恢复确认比较新旧全部键，包括新增的可选项。
- 公告：按浏览器本地时区输入，旁边显示 UTC；无效日期不自动顺延。
- CSV：改为固定导出起点、每页 500 条读取，不再截断到 2000 条；列表仍显示最近 2000 条，完整记录通过导出查看。
- 首页刷新：待办、系统五格与近七天费用一起刷新。
- 预算：50% 卡片接入关闭操作；80%/100% 不提供关闭。未知响应保留请求编号。
- 预览：三位标记“预览合成”的用户，分别正常、即将到期、额度恢复结果未知；原有预览数据不覆盖。
- 回滚模拟：独立无公网入口、无 Cloudflare 部署凭据的适配器，使用独立模拟表；不修改实际发布状态、账本或生产。

## 明确保留的验收边界

- 真实手机订阅与收到 Web Push：用户已决定稍后验收。
- Cloudflare 实际版本回滚：用户已决定只模拟，本次未执行。
- 公网预览的全域 Access 会拦截未登录探测；管理保护可以验证，应用及开关响应内容须登录后复查，不能把登录跳转当成内容检查通过。
- 本机签名 JWT 的重新验证流程不是用户在 Cloudflare 浏览器完成重新登录的证明。
- 本次不合并 main，不部署生产；公开预览复查通过后再进入发布确认。
