## 重点能力与具体缺口

1. **费用按日、按任务**：`finance/costs` 返回日 × 任务汇总；页面表格保留任务维度。`CostChart` 将相同日期合并，因此当前图形仅按日，尚无按任务图形切换。`RecentCosts` 的真实近 7 天接口支持跨月；缺少时间戳的旧请求明确未知，不补造历史。
2. **配置确认与恢复**：普通修改展示改前 → 改后；版本恢复、环境默认恢复、CAS、同请求重试已实现。确认列表遍历当前草稿键；恢复目标若新增当前不存在的可选 `quotaSummary`，该新增项可能未列入确认，需改为前后键集合。新鲜 Access、本地持久化版本恢复已有测试，但实际重登录后确认及未来请求消费仍须浏览器/集成验收。
3. **公告**：已接到 `MainlineApp`；`/workout/` 前缀隐藏，关闭仅影响当前组件内同一公告；服务端单条、单行、七天上限、话术检查和到期已有测试。仍需验证全部训练入口是否均由该前缀覆盖，以及 320px 长文截断、关闭和跨页面行为。默认公告文案是管理员可编辑内容，不自动翻译。
4. **审计 CSV**：目前只导出最近 2000 条，无分页/日期范围或截断提示；不能称为全部记录导出。对象短 ID 与表格转义已实现；`actor` 为管理员 Access 身份，应与“只含短 ID”要求明确区分。需专门测试 BOM、换行/公式字符、申请说明不外泄以及导出审计。
5. **首页五格**：AI 开关、账本、剩余预算、待核算预留、24 小时错误已经接线；错误数按真实 24 个小时分桶求和，不使用八天累计。数据失败显示不可用。顶部刷新目前只刷新外壳待办/session，五格和近 7 天组件首次加载后不会随该刷新再次请求，需统一刷新触发。
6. **预算提醒**：50/80/100 阈值及仅关闭 50% 的后端接口存在；当前待办卡尚未接 50% 关闭按钮。80/100 主动提醒与条件消失移除需统一通知集成验证。
