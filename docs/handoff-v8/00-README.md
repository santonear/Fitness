## 已确认的产品决策

| 决策 | 结论 |
|---|---|
| 视觉主题 | 四套：青瓷（默认）、留白、静奢、撞色；在 设置 › 外观 手动切换；保留"更多模板"入口 |
| 撞色底色 | 象牙色 `#FAF6EC` |
| 芽芽形象 | 保持现有 3D 形象（四种状态图）；浮动按钮在初见、草案、结束反馈、记录活动隐藏，训练中改为顶部小头像，不得遮挡主操作 |
| 图标 | 保留 Soft Ceramic 陶瓷图标，导航三项按四套主题重新上釉（签名组件 `NavIcon`，共 9 个签名组件） |
| 外发同意 | 轻量同意：发送按钮即授权，可展开查看发送字段；身体资料与历史默认不发送 |
| 没有 AI 资格 | 本地规则生成基础计划，可立即练；未满 18 岁只开放手动训练与记录 |
| 签名动效 | 保留按压回弹、旋转流光描边 + 呼吸背光、胶囊 → 面板流体变形；流光主卡每屏最多一张；训练中关闭持续动画 |
| 首次引导 | 和芽芽对话，只问三件事 + 安全确认；以"你也许想说"辅助回答 |
| 计划 | 不绑日期，只规定训练单与每周次数，用户随时开始 |
| 提醒 | 只保留用户设置的提醒，默认关闭，"只是提醒，不代表必须练"；复用 V6.2 前台引擎，不发系统推送 |
| 训练中 | 自主节奏：不倒计时、不自动开始、动作顺序自由、默认值一键完成 |
| 计划外活动 | 可手动记录（如散步 1 小时），计入回顾 |
| 记录原则 | 一切如实记录，含少练原因；完成记录只读 |
| 回顾 | 周 / 月回顾：事实 → 规律 → 最多 1 条建议；用户确认后生成新版本 |
| 芽芽话术 | 先肯定事实 → 适度鼓励 → 中立陈述差距 → 给方案并让用户选择 |
| 导航 | 训练 / 计划 / 回顾 三个标签；设置从右上角进入；动作库并入计划，进度并入回顾 |
| 后台 /admin | 纳入重构，放在最后一步 |
| AI 架构评审 | 应用内（含后台）不设入口；相关契约只写在规范第 2 部分第 8 节与 `docs/architecture/` |

## 相对 V7.1 原型的主要变化

1. 主题从 Atlas / Serene / Orbit 换成四套有独立气质的主题，并改为"令牌 + 签名组件"的架构。
2. 10 屏引导表单 → 三个问题的对话。
3. 按日期排计划 → 训练单 + 每周次数；日历只用于查看历史。
4. "今日"首页 → "下一次"首页。
5. 训练记录 → 自主节奏训练 + 结束反馈（含少练原因）。
6. 新增：计划外活动记录、周 / 月回顾、计划版本页、可选提醒。
7. AI 任务：CREATE_PLAN → ONBOARD_PLAN；新增 ADJUST_TODAY、PERIOD_REVIEW；废弃 MANAGE_PLAN 与按日期的候选。

## 原型说明

- 原型是单文件 HTML，用于表达交互和视觉，不代表生产实现方式。
- 所有数据为演示数据（固定日期 2026-10-09 周五），不连接模型、后端或数据库；芽芽的回复由本地规则模拟。
- 原型在线加载 Google Fonts；生产必须打包子集字体。
- 月回顾中的数字是静态演示值；周回顾会随原型中的操作实时变化。
- 已用 Playwright 走查：四套主题切换、初见到保存计划、胶囊变形、训练中完成组/修改数值/换动作/暂停结束、反馈保存、记录活动、采纳周建议、芽芽对话的短版与换动作提案、设置与外观；并断言不存在 AI 架构评审入口；无脚本错误。
