## 动作过程（每条注明来源）

1. 起始：杖式坐，双腿并拢伸直，脊柱直立，双手轻放在大腿旁的地上（S2、S3、S4；Bo 的 drzio 图同为此姿势）。
2. 收弯腿：保持髌骨朝上，先屈膝把腿收向胸前，收到最近后整条腿向侧面放下（S2）；放下后小腿外侧平放在地上（Mercy 页面）；膝向外、向下沉到地面（S3），膝留在地上（S4）。
3. 脚的位置：脚底贴伸直腿的大腿内侧，但不压到大腿下面（S2）；脚跟尽量靠近会阴（S3）；弯腿脚掌主动，脚背压地、脚跟推向伸直腿大腿内侧（S1“Explore the pose”）。
4. 两腿夹角：初学者约 90°（S2）；进阶时弯腿膝向后拉，夹角大于 90°（S2、S3、S1）。膝痛时把弯腿膝收近伸直腿（S1）。
5. 膝浮离地面时：在弯腿大腿下垫毯或砖（S1、S3）。
6. 髋的动作：弯腿股骨屈、外展、外旋（S1 解剖说明）；“大幅外旋”，前屈时大腿不能跟着内旋（S6）。具体度数：未查到。
7. 手：先放在髋两侧地上或身后，帮助伸展脊柱（S2、S3）；前屈时握伸直腿的膝、踝或脚，够不到时用带子（S2、S5、S1）。
8. 前屈：吸气伸展脊柱，呼气从髋关节前屈，骨盆前倾带动躯干（S2、S3、S4）；躯干略转向伸直腿（S3、S5、S7）；最后放松头颈，额头朝向伸直腿的膝或小腿（S3），下巴朝脚趾（S4）。
9. 退出：吸气慢慢起身，换另一侧重复（S2、S4、S7）。
10. 常见错误：为了让头碰膝而拱背（S1、S2、S5）；低背后仰（S1）；用力拉进前屈（S1）；伸直腿膝锁死过伸，可在膝下垫毯（S1）。

## 形态要点（复核对照用）

1. 起点是杖式坐；弯腿先屈膝、膝朝上收近，再整条腿向外侧落下（S2）。
2. 最深帧：弯腿的膝和大腿外侧落在地上或接近地面，膝朝外；脚底贴在伸直腿的大腿内侧，脚跟靠近会阴（S1 图、S3、S4）。
3. 两腿夹角约 90°（初学者），进阶可大于 90°（S2）。
4. 前屈由骨盆前倾带动，背保持长，头最后放松向伸直腿的膝或小腿；不能拱背硬把头碰到膝（S1、S2、S3）。
5. 双手握伸直腿的脚、踝或小腿（S1 图、S2）。
